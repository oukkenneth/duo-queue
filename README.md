# Kenny’s Wedding Lobby

A local, mobile-first React + Vite invitation for May. Exactly two main states, with server-side Resend RSVP notifications. Visual state resets on refresh; each outcome is sent at most once per tab session. See [RSVP.md](RSVP.md) for setup, security boundaries and testing.

## Run

Install Node.js 20.19+ or 22.12+, then from this folder:

```sh
npm install
npm run dev
```

Alternatively use pnpm (the included pnpm-lock.yaml pins the verified dependencies): `pnpm install`, `pnpm dev`.

Production: `npm run build`. Preview that build: `npm run preview`.

## Components

App → InviteScreen or AcceptedScreen. Shared components: Artwork, Crest, Divider, GoldPanel, GameButton, ParticleLayer. InviteScreen composes InfoPanel, NotesPanel and DeclineButton. AcceptedScreen composes LoadingBar. All are intentionally together in main.jsx to keep this tiny project easy to maintain.

The first three DECLINE clicks move the button and show the three requested messages. The fourth displays the closable inline decline message. ACCEPT MATCH changes to the autumn scene. Loading reaches 100% in 4.2 seconds. Buttons support keyboard input and visible focus. Decorative motion respects reduced-motion preferences.

## Swap artwork

Replace `public/assets/characters/hero.png` (landscape 3:2 recommended) and `accepted-autumn.png` (portrait 2:3 recommended), keeping filenames; no code changes needed. These composed images contain both tacticians and scenery. To swap one tactician independently in normal rendering, supply a new composed image or adapt Artwork to render separate cutouts. `choncc.png` and `doughcat.png` currently serve as image-error fallbacks, not independent foreground layers.

All paths live in src/config.js. Use relative filenames through its `asset()` helper. The optional background/decor slots are reserved as null and not currently consumed. No giant base64 assets. The four SVG icons are separate files. Theme colors are CSS variables. Hero cropping is controlled by `.artwork > img` in styles.css.

## Deploy

Deploy the source project to Vercel (Vite preset, build: `npm run build`, output: `dist`). The root `api/rsvp.js` provides the serverless endpoint. Configure the three server variables in [RSVP.md](RSVP.md). Static-only hosting cannot deliver RSVP notifications.

This first pass is local and has not been published. The noindex meta tag discourages indexing; it is not password protection. Configure host-level access protection if you need a restricted audience.

## Material visual differences

- Custom generated art closely follows the characters and reference, but is not an exact reproduction. The Rhode Island coast is stylized, not a geographically precise landmark rendering.
- The phone mockup, surrounding table props, and ornamental handwriting are omitted; the invite itself fills the mobile screen.
- Gold ornamentation is simpler than the painted reference. Heading typography uses the installed Georgia serif rather than TFT’s proprietary face.
- Flowers are baked into the composed hero; the notes duck is a small emoji rather than a separate illustrated asset.
- The decline button moves within its compact action area rather than roaming over the entire screen.
- Small phones can scroll vertically; there is no horizontal page navigation or third page.
